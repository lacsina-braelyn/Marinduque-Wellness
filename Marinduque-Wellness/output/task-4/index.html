Few-Shot Prompting

Few-shot prompting provides examples of the desired format before asking Copilot to generate similar content.

Example 1

Category: Physical Wellness
Description: Choose safe drinking water throughout the day.

Example 2

Item: Take a mindful break
Category: Mental Wellness

Few-Shot Prompt to Submit to Copilot

Act as a frontend web developer. Create additional wellness checklist items for the Marinduque Wellness website using the following format. Example 1: Item: Drink safe water Category: Physical Wellness Description: Choose safe drinking water throughout the day. Example 2: Item: Take a mindful break Category: Mental Wellness Description: Pause, breathe slowly, and give yourself time to relax. Generate four additional general wellness habits using the same Item, Category, and Description format. Include a mix of physical wellness, mental wellness, and community wellness habits. Render the four new items as an accessible interactive checklist using HTML, CSS, and vanilla JavaScript. Do not provide personalized medical advice.

EXPERIMENT B

Role Assignment

In this experiment, Copilot takes on the role of an accessibility reviewer to examine the same Marinduque Wellness interface.

Role Assignment Prompt

Act as a frontend accessibility reviewer. Examine the Marinduque Wellness website, including index.html, style.css, and script.js. Review the interface for semantic HTML, heading structure, keyboard navigation, form labels, checkbox accessibility, visible focus indicators, color contrast, text readability, and mobile responsiveness. Identify specific problems supported by the code. Recommend targeted improvements without changing the project's scope or adding external frameworks, backend services, or live health data. Explain why each recommended improvement matters and provide corrected code examples where appropriate. Do not claim that an issue exists unless you can identify evidence, and do not claim that a fix has been tested unless it has actually been tested.

Actual Copilot Response

Observation — Experiment B

Example observation: Assigning Copilot a specialized accessibility role directs its attention toward usability and accessibility concerns rather than only visual design. Review the actual response to see whether it identifies specific issues and recommends practical improvements for the existing website.
